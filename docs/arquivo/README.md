# Arquivo — documentos de sessões antigas

**Nada aqui descreve o estado atual do projeto.** O estado atual está em
[`../HANDOFF.md`](../HANDOFF.md).

Estes arquivos estavam na raiz do repositório e foram movidos para cá em
2026-09-29. Eram relatórios e instruções de sessões de trabalho anteriores, e
vários passaram a contradizer a realidade — o `BUILD_STATUS.md` e o
`PROMPT_PARA_CONTINUAR.md`, por exemplo, instruem a "fazer o build funcionar",
quando o build funciona há dias. Na raiz, quem chegasse ao projeto partiria de
uma premissa falsa.

Ficam guardados porque registram o que foi tentado e por quê.

| Arquivo | O que era |
| --- | --- |
| `BUILD_STATUS.md` | Diário da correção dos erros de build de 2026-09-20 |
| `PROMPT_PARA_CONTINUAR.md` | Instrução para uma IA continuar aquela correção |
| `DEPLOYMENT_SUMMARY.md` | Resumo de um commit de 2026-09-20 |
| `FIX_SUMMARY.md`, `INSTRUCTIONS.md` | Correção do erro `reading 'length'` na biblioteca |
| `HANDOFF_2026-09-18.md` | Versão antiga do `docs/HANDOFF.md` (estava em `Claude outputs/`) |
| `scripts-de-build/` | `.bat`/`.vbs` que salvavam a saída do build num arquivo durante aquela depuração; o comando normal é `npm run build` |
